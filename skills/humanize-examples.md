# Humanize Examples

## Activation Gate

Load only when the user explicitly requests examples, teaching, before-and-after
comparisons, or passes `--with-examples` to the shortcut command. Do not load in
ordinary generation, audit, or humanization. These examples demonstrate repair
operations; they are not factual sources or style references.

## Use Rule

Identify the defect and transfer only the repair principle. Never copy names,
facts, images, sentence rhythm, or cultural details from an example into the
user's text.

### Inflated Significance To Observable Fact

Before: `The opening marked a pivotal milestone and reflected a broader transformation.`

After: `The clinic opened on Monday and added two evening shifts.`

Repair: replace announced importance with the event and its observable consequence.

### Contrast Frame Or Comparison Ladder To One Real Criterion

Before: `这不是一次普通调整，而是一场重塑；它比旧方案更快，比传统方法更稳，比所有替代方案更有生命力。`

After: `新方案把夜间审核从两轮减到一轮，代价是值班人员必须当场记录例外。`

Repair: keep the distinction that changes the claim; remove ornamental escalation.

### Time Card To Narrative Bridge

Before:

```text
### 下午
她再次来到办公室。
```

After: `午饭后的雨一直没停。她把湿伞留在门外，再次推开办公室的门。`

Repair: carry one residue through elapsed change into the first new action.

### Orphaned Interaction To Consequential Uptake

Before: `“你早就知道。”他说。走廊里的灯忽然灭了。`

After: `“你早就知道。”他说。她没有否认，只把门卡压在掌心。走廊的灯就在这时灭了。`

Repair: add speech, action, silence, interruption, or explicit deferral before shifting away.

### False Precision To Perceptual Scale

Before: `他的手向前移动了三厘米，停了两秒。`

After: `他的手刚探过去，又停在她能察觉、却还没有碰到的位置。`

Repair: keep exact values only when measured or consequential; otherwise use felt relation.

### Over-Cleanup To Preserved Voice

Before: `“我没有生气。我只是暂时不想讨论这件事。”`

Over-clean rewrite: `“我并未生气，只是不想继续讨论。”`

Preserving rewrite: `“我没生气。算了，我现在不想说这个。”`

Repair: keep the retreat, correction, and register instead of polishing them into neutral prose.

### Vague Attribution To Sourced Scope

Before: `专家普遍认为，这项技术将产生深远影响。`

After: `报告援引的三名实验室负责人认为，它可以缩短样本登记时间；报告没有评估长期影响。`

Repair: name the available source and limit the conclusion to what it supports.

### Missing Word To Minimal Restoration

Before: `她把名单交给，转身去锁门。`

After when context identifies the recipient: `她把名单交给值班老师，转身去锁门。`

Repair: restore the required grammatical slot from evidence. If the recipient is
not recoverable, mark the ambiguity instead of inventing one.
