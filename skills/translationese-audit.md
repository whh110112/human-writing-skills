# Translationese And Cross-Language Fidelity

## Aim

Keep an explicitly translated, bilingual, or cross-language draft idiomatic in its
target language without flattening the source's meaning, register, cultural logic, or
speaker identity. This is an editing module, not a request to disguise authorship.

## Activation Gate

Use only when the user supplies a source text and target language, asks for a
translation or localization, identifies a draft as translated, or explicitly requests
a translationese review. Do not activate merely because a text is written in Spanish,
Portuguese, French, English, Chinese, Arabic, Japanese, Latin, or another language.

## Evidence Hierarchy

1. The supplied source, target-language brief, terminology list, and publication rules.
2. Established character language cards, narrator baseline, or institutional house style.
3. Target-language genre conventions supported by an approved reference sample.
4. General linguistic intuition only as a tentative review lead.

Do not replace a precise foreign concept, regional usage, legal term, scientific term,
name, quotation, or deliberate register with a smoother but less faithful substitute.

## Drafting Rules

1. Establish source language, target language, audience, translation convention, and
   non-negotiable terms before rewriting.
2. Transfer function before surface order: preserve what a line does (warns, withholds,
   flatters, qualifies, reports, jokes, or threatens), not the source sentence shape.
3. Rebuild idiom, information order, connectors, punctuation, forms of address, and
   paragraph rhythm for the target language and selected genre.
4. Keep cultural references legible through context or a brief necessary gloss; do not
   erase them into generic international prose.
5. In fiction, preserve each speaker's target-language baseline. Do not add foreign
   words, phonetic accents, slang, or honorifics merely to advertise nationality.
6. In news, academic, legal, technical, and official text, preserve numbers, dates,
   citations, quotations, names, terminology, source attribution, and calibrated
   uncertainty before improving flow.

## Audit Method

Compare source and target by unit. Mark only evidence-backed issues:

- source-language word order or connector logic copied into a target language where it
  sounds translated rather than intentional
- literal idiom, false friend, or culture-bound image whose target effect is unclear
- imported punctuation, address, politeness, tense, or paragraph convention that does
  not fit the target language or house style
- repeated source-like rhetorical frames that make the target prose mechanically
  balanced or over-explained
- a character, narrator, or institution whose established target-language register is
  replaced by neutral translation voice
- a fluent rewrite that changes claim strength, time, agency, attribution, relation,
  ambiguity, technical meaning, or cultural implication

For every proposed repair, state the source function, the target-language problem,
and the smallest faithful alternative. If no source is supplied, label the finding as
possible translationese rather than asserting an error.

## Output


Do not turn every target-language sentence into the same polished global register.
