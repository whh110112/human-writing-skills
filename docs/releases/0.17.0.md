## 多 Agent 长篇写作与逐块审稿

从已确认的大纲开始，为超长小说、报道、论文和报告建立可恢复的五角色写作流程：
大纲检查、分块规划、逐块写作、逐块独立审稿，以及最终上下文衔接审核。

- 默认每块 5000 字符，可选择单词单位。60000 字符建立十二个写作任务和对应审稿任务。
- 默认按依赖顺序写作；显式独立起止状态契约支持受限并行。
- 交接累计状态和待承接事项；变化或解决事项需要实际正文引文。
- 逐段审稿回执、当前草稿摘要校验、认领标识和返修失效规则保护完整流程。
- 新增六个 CLI/MCP 写作协调操作、分页上下文读取和中英文指南。
- DSH 0.3.0 同步包含这些能力，按需加载详细协议。

## Outline-To-Manuscript Multi-Agent Writing

The core now coordinates outline checking, block planning, writing, independent
per-block editing and final continuity review. It snapshots canonical inputs,
carries approved state and unresolved threads, rejects stale claims, invalidates
dependent work on revision and requires coverage before assembling the manuscript.

The host supplies models and native subagents. Missing delegation is disclosed as
sequential role passes. Editorial meaning and literary quality remain model-reviewed;
the deterministic checks verify coordination and evidence structure.
