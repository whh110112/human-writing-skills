Human Writing Skills 0.16.1 fixes runtime, audit coordination, and distribution issues
found in a release-readiness review. The separately versioned DSH bundle is 0.2.1.

- Reject malformed prompt arguments without terminating the MCP stdio server.
  Handle JSON-RPC batches, notifications, invalid envelopes, and prompt errors.
- Constrain audit plans, state, prompts, and coverage-report paths to their package.
  Reject malformed or empty-required-task plans instead of incorrectly passing coverage.
- Serialize claims and submissions across processes, write reports/state atomically,
  preserve submitted ownership, and hash exactly the saved report bytes.
- Return the complete assignment when claiming a task.
- Reject browser origins and oversized/invalid HTTP request bodies; implement
  notification/unsupported-method status codes and IPv6 loopback binding.
- Preserve MIT license text in SkillHub packages and remove dangling DSH manifests.
- Separate DSH release events from Python, ClawHub, and SkillHub publication;
  validate core versions and preserve existing release assets.
- Verify installed wheels outside the source tree and run the packed DSH Python
  runtime in an isolated temporary directory.

Requires Python 3.9+. DSH uses the bundled stdio runtime and requires Python on PATH
or an explicitly configured `pythonCommand`.

Coverage receipts record reviewers' declarations; they do not prove semantic review.
Writing-quality improvements still require independent fluent-reader evaluation.
